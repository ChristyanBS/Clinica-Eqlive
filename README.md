# 🏥 Clínica Eqlive - Website v2.1

Website moderno e responsivo para a Clínica Eqlive, especializada em medicina integrativa e funcional. Redesignado com inspiração em Parsley Health com design profissional e organizado.

## ✨ Sobre o Projeto

A Clínica Eqlive é referência em saúde integrada em Itaboraí (RJ). Este website apresenta uma abordagem holística de saúde com design premium, gradientes sofisticados e navegação intuitiva.

## 🐛 Troubleshooting

### Site não abre?
```
✅ Verifique caminho do arquivo
✅ Tente outro navegador (Chrome recomendado)
✅ Limpe cache (Ctrl+Shift+Delete)
```

### Sem imagens?
```
✅ Normal - vêm de URL externo (Unsplash, próprio site)
✅ Requer internet para imagens remotas
✅ Funciona offline (sem imagens)
```

### Botões não funcionam?
```
✅ Links internos sempre funcionam
✅ WhatsApp requer app/web configurado
✅ Verifique console (F12 → Console)
✅ Verificar JavaScript no browser
```

### Menu mobile não abre?
```
✅ Verificar se JavaScript está ativado
✅ Testar em incognito (sem extensions)
✅ Limpar cache e cookies
```
