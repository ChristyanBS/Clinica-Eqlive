Tipos principais:
feat: Uma nova funcionalidade (ex: feat: adiciona botão de agendamento whatsapp)

fix: Correção de um bug (ex: fix: corrige alinhamento do logo no mobile)

docs: Mudanças na documentação (ex: docs: atualiza readme com instruções de instalação)

style: Formatação, pontos e vírgulas, sem mudar lógica (ex: style: formatação com prettier)

refactor: Refatoração de código (melhoria sem mudar funcionalidade)
