## 🆘 PROBLEMAS?

**Site não abre?**
- Verifique caminho do arquivo
- Tente outro navegador
- Limpe cache (Ctrl+Shift+Delete)

**Sem imagens?**
- Verifique internet
- URLs externo (Unsplash)
- Normal offline

**Estilos estranhos?**
- Reload (Ctrl+R)
- Hard reload (Ctrl+Shift+R)
- Limpe cookies

**Botões não funcionam?**
- Links internos sempre funcionam
- WhatsApp requer app/web configurado
- Verifique console (F12)
