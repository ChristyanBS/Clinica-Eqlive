## 🔧 TECNOLOGIAS UTILIZADAS

```
Frontend
├─ HTML5 (Semântico)
├─ Tailwind CSS (Styling)
├─ JavaScript Vanilla (Interatividade)
└─ Lucide Icons (Ícones)

Tipografia
├─ DM Sans (Google Fonts)
└─ Playfair Display (Google Fonts)

Performance
├─ CDN externo (Tailwind/Fonts)
├─ Imagens otimizadas (Unsplash URLs)
└─ Sem dependencies pesadas
```

### Por que essas escolhas?

- **Tailwind CSS:** Rápido, responsivo, fácil de manter
- **Vanilla JS:** Sem dependencies, performance ótima
- **Google Fonts:** Confiável, rápido, premium
- **Lucide Icons:** Consistentes, customizáveis, modernas
